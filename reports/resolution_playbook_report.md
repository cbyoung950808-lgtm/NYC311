# 자치구별 종료 시간: 비슷한 업무끼리 맞춘 비교 (v2, 검증·수정판)

> (`NYC311_Analysis_Playbook.md`의 작업 가설)

- **작성**: 2026-11-23. v1(같은 날)을 검증하고 수정한 판입니다.
- **v1 보관본**: `backup/20261123_before_dashboard_v2/`
- **코드**: `scripts/resolution_playbook/resolution_playbook_analysis.py`
- **결과 파일**: `reports/resolution_playbook/` (`B_assessment.csv`, `C_candidates.csv`, `C_closure_text_candidates.csv`, `C_detail_drivers.csv`, `closure_text_examples.csv` 등)
- **보존**: 원본·interim·processed 데이터, 기존 EDA 결과는 수정하지 않았습니다. 전처리를 다시 실행하지 않았습니다.

## 1. 입력과 기준

```yaml
analysis_start: 2025-11-01
analysis_end_exclusive: 2026-11-01
observation_as_of: 2026-11-11        # 가정: 이 시각 전까지 기록된 종료만 사용 (점검: 2026-11-12)
data_source: 311_Service_Requests_from_2020_to_Present_20261112.csv (processed parquet로 읽음)
timezone: America/New_York           # 원자료 시각을 변환 없이 사용
boroughs: all_five
```

**실제 수집 범위와 대상**
- **실제 접수 범위**: 2025-11-01 21:09 ~ 2026-10-31 21:09.
- **건수**: 전체 3,963,959건(전수)에서 번호만 다른 중복 의심 1,791건을 뺀 3,962,168건(기본 분석 대상).
  - 이 문서는 「번호가 다르면 별도 접수」라고 하지만, 기존 EDA 기준을 유지했습니다. 차이는 0.05%입니다.
- **결측**: 자치구 미지정 3,794건(비교에서 제외), 세부 유형 미기재 74,639건(「(미기재)」로 묶음), 담당 기관 결측 0건.

### 1-1. 지표별 계산 대상

| 지표 | 대상 | 건수 |
|---|---|---:|
| 종료 시간 (이 분석) | 기준 시각 전 종료 시각이 있고, 종료 ≥ 접수 (같은 초 포함) | 3,801,995 |
| 종료 시간 (기존 EDA, 민감도용) | Closed, 처리 시간 > 0, 상태·종료일 불일치 아님 | 3,729,839 |
| 7일 안에 종료 기록 없음 | 기준 시각 7일 전까지 접수, 종료 < 접수 기록 제외 | 3,960,804 |
| 30일 안에 종료 기록 없음 | 2026-10-11 23:59:56까지 접수, 종료 < 접수 기록 제외 | 3,734,534 |

**특이 기록의 처리**
- **종료 < 접수(1,364건)**: 건수에는 남기고, 시간·지연률에서 제외했습니다.
- **미래 날짜 1건**: 종료 시각이 2026-12-14입니다. 기준 시각 이후라 「기준 시각 현재 미종료」로 봅니다.
- **같은 초 종료**: 62,481건.
- **명시적 중복 문구 종료**: 193,813건.
- **같은 초 + 중복 둘 다**: 20,243건. 제외할 때 한 번만 뺐습니다.

### 1-2. 두 종료 기준은 무엇을 재는가

| | 기존 EDA 기준 (대시보드의 「절반·90%」) | 이 분석의 기준 |
|---|---|---|
| 종료로 보는 것 | 상태가 Closed이고, 종료 − 접수 > 0이며, 상태와 종료일이 서로 맞는 기록 | 기준 시각 전에 종료 시각이 기록된 신고(상태 값과 무관) |
| 재는 것 | 「정상적으로 닫힌 기록」의 소요 시간 | 「종료 시각이 남았는가와 그 시각」 |
| 포함 차이 | 같은 초 종료(62,481건), 상태는 Closed가 아닌데 종료 시각이 있는 19,220건 제외 | 둘 다 포함 |
| 5개 자치구 전체 중앙값 | **8.6시간** | **7.9시간** |

- 두 값은 **다른 지표**라서 같은 지표처럼 섞어 쓰지 않습니다.
- 어느 쪽이 정답인지는 「무엇을 종료로 볼 것인가」의 선택입니다.
- 대시보드의 「절반·90%」 카드는 기존 EDA 기준이고, 「맞춘 비교」 카드는 이 분석의 기준이라서 그 점을 화면에 적었습니다.
- 이 분석의 비교를 기존 EDA 기준으로 다시 계산한 결과(`eda_rule`)는 3절 표의 「기준별 범위」에 들어 있습니다.

### 1-3. 관찰 기준 시각은 가정입니다

- **근거**: 원본 파일 이름은 2026-11-12입니다. 하지만 기록된 종료 시각과 갱신 시각은 2026-11-11 이른 시각에서 거의 끝납니다(종료 11-10 1,494건 → 11-11 15건).
- **확인할 수 없는 것**: 모든 신고의 상태가 그 시점까지 반영됐는지는 이 자료로 확인할 수 없습니다.
- **처리**: 주 기준을 2026-11-11 00:00으로 잡았습니다.
- **2026-11-12로 둘 때와의 비교**: 5개 자치구 전체 30일 지표의 분모는 3,740,757건 → 3,730,983건, 비율은 9.72% → 9.72%입니다. 7일 비율 20.27%와 중앙값 7.91시간은 그대로입니다. 자치구별 값의 차이도 0.01%p 이내입니다.

### 1-4. 종료 문구 분류

- **원칙**: 명시적인 문구만으로 분류합니다. 대표 사례는 `closure_text_examples.csv`에 있습니다.
- **종료 건 중 비율**: 위반·문제 없음 49.0%, 조치·위반 발부 기록 19.7%, 출입·확인 실패 9.6%, 기타 5.4%, 중복 5.1%, 안내·접수 확인 5.0%, 점검(결과 불명) 3.6%, 관할 아님·다른 기관 1.9%, 미기재 0.9%.
- **「조치·위반 발부 기록」은 실제 수리 확인이 아닙니다.** 「위반 발부(Violations were issued)」, 「세입자가 해소됐다고 함」 같은 기록 문구일 뿐입니다.
- **「중복」은 거짓 신고라는 뜻이 아닙니다.** 다른 신고와 합쳐 닫은 기록입니다.
  - 주택보존개발국(HPD): 「건물 전체 문제로 다른 세입자가 이미 신고, 원래 신고는 아직 열려 있음」.
  - 환경보호국(DEP)·교통국(DOT): 「이미 접수된 신고로 처리 중」.
- **「다른 기관에 요청」은 이관 사실의 기록일 뿐입니다.** 지연의 원인이라는 증거가 아닙니다.
- **수정한 오분류**:
  - 「Notice of Violation was not issued」(46건): 조치 → 위반 없음.
  - 「meets its standards」: 점검 → 문제 없음.
  - 「earlier complaint about the same location」: 점검 → 중복.
  - 경찰청의 안내 문장 「may be referred」: v1 검증 단계에서 「다른 기관」에서 제외했습니다.

## 3. 비슷한 업무끼리 맞춘 비교

**방법**
- **비교 대상**: 각 자치구를 나머지 네 곳과 비교합니다. 자치구마다 비교 상대가 달라서 **보정값으로 자치구 순위를 만들지 않습니다.**
- **맞춘 조건과 가중**: 민원 유형·세부 유형·접수 월·담당 기관이 같은 묶음 중 양쪽에 각각 3건 이상 있는 묶음만 씁니다. 두 집단의 묶음 비중을 평균 낸 공통 비중으로 가중합니다.
- **보고 기준**: 양쪽 50건 이상, 포함률 65% 이상.
- **계산 검증**: 브롱크스 자치구 전체 중앙값을 SQL로 따로 계산했더니 결과가 정확히 일치했습니다.
- **기준을 바꿔도 같은가 (민감도)**: 6가지 기준으로 다시 계산했습니다.
  1. 월(기본)
  2. 분기
  3. 같은 초·중복 문구 종료 제외
  4. 기존 EDA 종료 기준 (중앙값만)
  5. 같은 날·장소·유형 묶음당 1건만 (반복 신고 영향 확인)
  6. 10건 미만 묶음 제외 (작은 묶음 영향 확인)
- **조사 후보**
  - 기본 기준에서 중앙값이 1.5배 이상 차이 나거나, 30일 지표가 5%p 이상 차이 나는 경우입니다.
  - 그중 **모든 기준에서 같은 방향이고 1.25배(또는 2.5%p) 이상 남은 경우만 「유지」**로 봅니다.
  - 7일 지표는 기본 기준에서 5%p 이상 차이 나는 조합이 없었습니다.

| 맨해튼 | 12.2 / 7.4 | 7.4 / 9.7 | 0.75 ~ 0.79 | 11.9% / 9.2% | 10.3% / 10.3% | −0.03 ~ −0.14 | 99% / 99% |
| 퀸스 | 4.9 / 10.0 | 6.6 / 6.2 | 1.04 ~ 1.08 | 9.6% / 9.8% | 10.0% / 9.2% | +0.8 ~ +0.9 | 100% / 99% |

**[사실]**
- 단순 비교의 차이(최대 약 5시간)는 맞추면 2.3시간 이내로 줄어듭니다.
- 맨해튼과 스태튼아일랜드는 방향이 반대로 바뀝니다. 브롱크스·퀸스는 기준에 따라 0.95~1.08배로, 사실상 차이가 없습니다.
- 7일 지표에서는 스태튼아일랜드만 모든 기준에서 약 3%p 낮게 남습니다(후보 기준인 5%p 미만).

**[해석 범위]** 「맞춘 뒤 남은 차이 = 지역의 순수한 영향」이 아닙니다. 맞추지 못한 조건(현장 특성, 세부 업무 순서, 기록 방식)이 남아 있습니다.

### 3-2. 조사 후보 (자치구 × 유형, 75개 비교 중)

| 자치구 · 유형 | 지표 | 맞춤 (해당 / 나머지) | 기준별 범위 | 판정 |
